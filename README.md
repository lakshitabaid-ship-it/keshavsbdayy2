# The Keshav Issue — Version 2

A new visual direction combining a vintage birthday invitation with comic-book / manga-inspired editorial storytelling.

## Files
- `index.html` — homepage
- `gallery.html` — 20-photo gallery
- `dossier.html` — five clickable About Keshav chapters
- `letters.html` — 11 interactive envelopes
- `style.css` — all styling, textures, layouts and visual treatments
- `script.js` — gallery, chapter and letter content/interactions

## Add Keshav's homepage photo
Upload `keshav-head.png` directly into the **root of your GitHub repository**, beside `index.html`. The homepage already references `keshav-head.png`. A transparent PNG works best for the portrait cut-out. If your image is not transparent, it will still display, but its background will remain visible.

## Add gallery photos
Upload these directly into the **root of your GitHub repository** (not into a folder):
`photo-01.jpg`, `photo-02.jpg`, ... `photo-20.jpg`.

The gallery currently shows designed paper placeholders until the matching photo files are uploaded.

## Personalise the text
Open `script.js`.
- Edit `galleryItems` to change the 20 photo captions.
- Edit `chapters` to replace the five sample chapter texts.
- Edit `letters` to add each sender's name and letter.

## Publish with GitHub Pages
Upload the files from this ZIP into a new repository (or a separate branch/repository), keeping them together in the root. Enable GitHub Pages from the repository's Settings → Pages.

No `assets` folder is required. The visual design is built into the HTML and CSS.
